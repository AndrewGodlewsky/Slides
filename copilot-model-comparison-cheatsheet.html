GitHub Copilot Model Cheat Sheet

When to use which model — matched to strengths, cost, and a cheaper near-equal alternative. Pricing & lineup current as of June 2026.

How cost works. Copilot bills these models from AI credits at the per-token rates below (1 AI credit = $0.01 USD). Your paid plan includes a monthly credit allowance; overage is charged at these rates. Code completions and next-edit suggestions are never billed — they stay unlimited on paid plans. Because output tokens dominate real cost, the "expensive" warnings below track the output column. Some models have a cheaper Default tier and a pricier Long-context tier that kicks in past the token threshold shown.

The one rule that saves the most money: tier your routing. Send simple work to a budget model, let a workhorse (Sonnet 4.6 / Gemini 3.5 Flash / GPT-5.4) handle the ~80% middle, and reserve flagships (Fable 5, Opus 4.8, GPT-5.5) for the hard 10-15% that genuinely needs them. 6. Model types — a 60-second primer

Before "which model," it helps to know "which kind of model." These six archetypes are the stable categories — names and versions change, but the jobs they're built for don't. Most real models wear two hats (Gemini 3.5 Flash is a workhorse and multimodal; Fable 5 reasons and sees), so treat these as lenses, not rigid boxes.

🧠 Reasoning / frontier

Think hardest before answering — they plan, self-check, and grind through long, ambiguous problems on their own.

Use for
  • Novel architecture, subtle/concurrency bugs, repo-wide migrations
  • Long autonomous tasks where being wrong is expensive
Skip for
  • Simple edits, boilerplate, high-volume work — slow & costly; you pay for thinking you don't need

Here: GPT-5.5 · Claude Opus 4.8 · Claude Fable 5

🐎 Balanced / workhorse

Strong all-rounders that deliver most of a frontier model's quality at a fraction of the cost.

Use for
  • The daily 80%: features, bug fixes, tests, code review, refactors
  • Your sensible default when in doubt
Skip for
  • Trivial throwaway tasks (overkill) or the hardest 10–15% (under-powered — escalate to a reasoning model)

Here: Claude Sonnet 4.6 · GPT-5.4 · Gemini 3.5 Flash

🤖 Agentic / coding-tuned

Trained to use tools, drive a terminal, and edit across many files in an iterative loop — built for agent mode.

Use for
  • CLI automation, multi-file implementation from a spec, tool orchestration
  • "Go do this whole task" delegated work
Skip for
  • Open-ended writing/analysis or deep conceptual reasoning beyond code

Here: GPT-5.3-Codex · MAI-Code-1-Flash · Raptor mini

⚡ Fast / small / budget

Lightweight and cheap — answer quickly with limited depth.

Use for
  • Explanations, summaries, classification, boilerplate, quick Q&A
  • High-volume batch jobs and routing/triage
Skip for
  • Complex logic or architecture — they stall or hallucinate; escalate the moment they get it wrong twice

Here: Claude Haiku 4.5 · GPT-5.4 mini/nano · GPT-5 mini · Gemini 3 Flash

📚 Long-context

Hold and recall very large inputs — hundreds of thousands to millions of tokens at once.

Use for
  • Whole-repo analysis, large documents, long logs/transcripts
  • Questions that span far more than a few files
Skip for
  • Short prompts — you pay a premium (and a surcharge cliff) for capacity you aren't using

Here: Gemini 3.1 Pro · Gemini 2.5 Pro · (1M modes of Sonnet / GPT-5.x)

🖼️ Multimodal

Understand images, video, audio, and PDFs — not just text.

Use for
  • Screenshot→code, UI-from-mockup, reading diagrams/charts/tables
  • Extracting data from documents and figures
Skip for
  • Plain-text coding — a text-only model is usually cheaper and just as good

Here: Gemini 3.5 Flash · Gemini 3.1 Pro · Claude Fable 5 (vision)

Bonus type — completion (FIM) models. The ghost-text autocomplete and next-edit suggestions in your editor run on a separate, code-specialized "fill-in-the-middle" model. You don't pick it and it's never billed on paid plans — so lean on it freely for the mechanical typing, and save the chat/agent models above for the thinking.
