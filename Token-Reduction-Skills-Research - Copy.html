CGitHub Copilot settings — the highest-ROI changes

From GitHub's own engineering guidance and the dedicated copilot-token-optimization guide. Ordered by impact. The first three take ~15 minutes total and hit all three token categories.

  1. Add output-control rules to .github/copilot-instructions.md ↓ output 40–70%
    e.g. "Code only, no explanation unless asked." and "Bullets over paragraphs." Output is the 5×-priced category, so this is the single biggest win. Output
  2. Shrink your always-on context files ↓ context every call
    copilot-instructions.md and AGENTS.md are re-sent on every interaction. Strip LLM-generated boilerplate; keep only short, specific rules. Split big ones and use applyTo: path scoping so they load only when relevant. Context
  3. Default to the Auto model ↓ cost + paid-plan discount
    Auto picks a right-sized model and earns the documented multiplier discount on paid plans. Pin Opus/GPT-5.5 only when a task truly needs it. Use Haiku (~4× cheaper than Sonnet) for simple edits. Output
  4. Use Ask Mode for simple questions, not Agent Mode ↓ 60–90%
    Agent Mode spends tokens on tool-call reasoning loops. A plain question doesn't need an agent. Context
  5. Disable unused MCP servers ↓ 100–500 tok / step
    Each tool's schema rides in context every agent step. 15 unused servers × 15 steps ≈ 265K wasted tokens. Input
  6. Configure Content Exclusion (Business/Enterprise) most reliable trim
    Tell Copilot which files/paths to skip entirely — generated code, vendored deps, large fixtures. Input
  7. Prefer CLI over MCP for deterministic data ↓ input
    Run gh pr diff / fetch files up front, then point the agent at them — no tool-call JSON schemas or reasoning overhead. Input
  8. Convert .docx/.pdf/.pptx/.xlsx to Markdown first (e.g. Microsoft MarkItDown) strips noise
    Raw office/HTML formatting is token-dense junk. Input
  9. Session hygiene ↓ context drift
    Close unused editor tabs and start fresh conversations — accumulated context silently inflates every turn. Keep the front of the session stable so prefix caching keeps hitting. Context
  10. Write precise prompts ↓ clarification loops
    "Add a null check to getUser()" beats "fix the user code" — fewer back-and-forth round trips. Output
